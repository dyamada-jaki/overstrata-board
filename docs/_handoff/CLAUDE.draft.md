# Overstrata 戦闘ボード — エージェント向けガイド

## このアプリは何か
TTRPG「Overstrata」の**プレイ中に使う戦闘ボード**。
AI-GMと音声でプレイしている卓で、誰か1人がスマホを操作し、キャラの位置・移動をみんなに見せる。
**アプリはルールを強制しない。補助として見せるだけ**（最終判断はGMとプレイヤー）。

## 技術スタック
- Vite + React + TypeScript（strict）
- テスト: Vitest（+ React Testing Library）
- サーバーなし。ブラウザだけで完結する

## コマンド
- `npm run dev` — 開発サーバー
- `npm run test` — テスト
- `npm run typecheck` — 型チェック
- `npm run lint` — Lint
- `npm run build` — ビルド

## ディレクトリ構成
```
src/
  domain/      ルール計算（純粋関数のみ。React を import しない）
  components/  画面部品
  data/        サンプルデータ・定数
```

## 守ること
1. **ルール計算は `src/domain/` の純粋関数に書く**。UIの中に計算を書かない
2. **`src/domain/` の関数には必ずテストを書く**
3. **スマホ縦画面（幅375px）を基準**に作る。PCでも崩れなければOK
4. 画面の文言は日本語
5. 依存パッケージを増やすときは、PR本文に理由を書く
6. **1つのPRは1つのIssueだけを扱う**。PR本文に `Closes #番号` を書く
7. Issueの「スコープ外」に書かれたことはやらない。必要だと思ったらPR本文で提案する
8. Issueに書かれていないルールを推測で実装しない。不明点はPR本文に「確認したいこと」として書く

## 完了の定義（Definition of Done）
- Issueの受け入れ条件をすべて満たす
- `npm run test` / `npm run typecheck` / `npm run lint` がすべて通る
- PR本文に「何をしたか」「どう確認したか」を書く

## ゲームのルール（このアプリに関係する部分）
- 戦場は正方形グリッド。**距離は「斜めは1マス目=1、2マス目=2、…と交互」**（例: 斜め2マス=3、斜め4マス=6）
  - 計算式: `max(dx, dy) + floor(min(dx, dy) / 2)`
- 移動力 = 基本5マス + 装備補正（軽装 ±0 / 中装 −1 / 重装 −2）
- 1手番の行動は5パターン: 接近 / 接近+攻撃 / 攻撃 / 攻撃+後退 / 後退（分割不可）
- 機会攻撃（すれ違いざまの攻撃）の概念はない
- 手番順は敏捷の高い順。「ラウンドの最後まで遅らせる」選択ができる

## 用語
| 日本語 | コード上の名前 |
|---|---|
| キャラ | `Character` |
| 味方 / 敵 | `side: 'ally' \| 'enemy'` |
