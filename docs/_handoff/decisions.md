# 戦闘ボード（Webアプリ）決定事項

開発手法: Orca（ADE）× GitHub Issue × Claude Code / Codex によるAI駆動開発。学び方は「手を動かしてからふりかえり」。

## 2026-09-25 構想
- 用途: 音声プレイ中、卓の誰かがスマホで操作して盤面を見せる戦闘ボード
- 入力: アプリ上で手入力（AI-GM出力の読み込みは将来）
- ルールの扱い: 補助のみ（範囲を表示するが強制しない）＝「自由優先」
- 距離: 斜めは交互に1→2（max(dx,dy)+floor(min/2)）
- 技術: Vite + React + TS、サーバーなし、ルールは src/domain の純粋関数＋Vitest、GitHub Actions CI
- 盤面: 10×10、座標ラベル A〜J × 1〜10（音声で「C-4」と言える）

## Sprint 1（Walking Skeleton）案
1. 雛形・CI
2. 盤面表示 ─┐ 並行可
3. 距離・移動範囲計算（domainのみ）─┘
4. サンプルキャラ4体の表示と移動

## 2026-09-26 進め方の見直し
- 全体像は docs/spec.md に持ち、Issueは「今すぐ作る一片」だけを1〜3本ずつ切り出す
- Issueには実装方法（関数名など）を書かない。エージェントが計画モードで立て、人間が承認する
- 実装手順はスキル（.claude/skills/implement-issue）に持たせ、Orcaでは `/implement-issue 番号` で着手する
- 詳細は workflow.md
