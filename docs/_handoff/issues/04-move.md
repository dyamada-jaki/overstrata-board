## 目的
キャラを盤面に出し、タップで動かせるようにする。ここで「戦闘が目に見える」最小の体験が完成する。

## やること
- `src/data/` にサンプルキャラ4体を用意し、初期位置に表示する
  - 味方2体（例: 戦士・重装、癒し手・中装）、敵2体（例: ゴブリン・軽装 ×2）
- キャラは丸いトークンで表示する。名前の1文字目を表示し、味方と敵で色を分ける
- 操作の流れ
  1. キャラをタップ → 選択状態になり、移動できるマス（#3 の `reachableCells`）が色つきで表示される
  2. 空いているマスをタップ → キャラがそこへ移動する
  3. 選択中のキャラをもう一度タップ → 選択解除
- 画面下に選択中キャラの情報を出す（名前・装備・移動力）

## 受け入れ条件
- [ ] 起動するとサンプルキャラ4体が盤面に表示される
- [ ] キャラをタップすると移動可能範囲がハイライトされる
- [ ] **範囲の外の空きマスにも移動できる**（アプリは補助で、ルールを強制しない）
- [ ] 他のキャラがいるマスには移動できない
- [ ] 移動したら選択が解除され、ハイライトが消える
- [ ] 移動処理（キャラ一覧と移動先を受け取って新しい一覧を返す関数）は `src/domain/` にあり、テストがある

## スコープ外
- キャラを画面から追加・削除する機能（次スプリント）
- 手番・行動パターン・HP（次スプリント）
- 状態の保存（リロードすると初期配置に戻ってよい）
