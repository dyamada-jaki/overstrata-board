## 目的
戦場のグリッドを画面に出す。音声プレイでも位置を言い合えるように、座標ラベルをつける。

## やること
- 10×10 の正方形グリッドを表示する（サイズは `src/data/` の定数で持つ）
- 列に A〜J、行に 1〜10 のラベルを表示する（例:「C-4」と呼べる）
- マスをタップすると、そのマスの座標を受け取れるイベントを用意する（今は画面下に「選択中: C-4」と表示するだけ）
- 座標の型 `Position { x, y }` と、座標をラベルに変換する関数を `src/domain/` に作る

## 受け入れ条件
- [ ] 幅375pxの画面で、横スクロールなしにグリッド全体が見える
- [ ] 各マスが正方形で、指でタップできる大きさがある
- [ ] マスをタップすると「選択中: C-4」のように表示される
- [ ] `toLabel({ x: 2, y: 3 })` が `"C-4"` を返し、テストがある
- [ ] 盤面外の座標を判定する `isInside(position)` があり、テストがある

## スコープ外
- キャラの表示（#4）
- 距離・移動範囲の計算（#3）
- 盤面サイズを画面から変える機能
