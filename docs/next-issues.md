- **作る順番の合意**: #32は複数端末共有を待たず、1台で準備・配置・選択・移動を使える形で完成した。#37の移動力設定と#33の追加・削除も完了し、続いて#34を進める。#33の実機確認で挙がったUI改善は#45・#46で別途検討する。作った画面を利用者と見ながら使い勝手を整え、複数端末での共有は後の段階で追加する
