## Issue B: 距離と移動範囲を計算する

**目的**

移動範囲を表示するための計算を用意する。画面は作らない。

**仕様**

[docs/spec.md](spec.md)「3.1 距離の数え方（移動）」「3.2 移動力」「2.3 移動」

**受け入れ条件**

- [ ] 距離の計算が spec.md 3.1 の表（右へ3=3 / 斜め1=1 / 斜め2=3 / 斜め3=4 / 斜め4=6 / 右4下2=5）をすべて満たすテストがある
- [ ] 向きを逆にしても同じ距離になるテストがある
- [ ] 装備の重さから移動力が出る（軽装5 / 中装4 / 重装3）テストがある
- [ ] ある位置・移動力・他キャラの位置・盤面の大きさから、移動できるマスの一覧が出せる
- [ ] 盤面の外、他キャラのいるマス、自分のいるマスが一覧から除かれるテストがある

**スコープ外**

- 画面表示（移動範囲のハイライトは別 Issue）
- 他キャラを通り抜けられるかの判定（[spec.md 5章](spec.md)の未決事項。今は「いるマスを除く」だけ）
- 地形・障害物

**依存**

- #1 の完了後に着手する（土台がないとテストが走らない）
