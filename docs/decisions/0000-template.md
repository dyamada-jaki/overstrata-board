## 背景
どの Issue で、何を決める必要があったか。仕様（spec.md）の根拠があればリンクする。

## 理由
なぜこれを選んだか。二重実装で比べた結果や、レビューの指摘など、根拠へのリンクを付ける。

## 選ばなかった案
比べた案と、選ばなかった理由（不採用 PR の作りなど）。

## 影響
