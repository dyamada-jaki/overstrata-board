## 2. 目的と範囲

倒れた駒をその場所に残し、通常の駒と見分けられるようにする。利用者が操作パネルで手動で切り替え、倒れている間は配置済みの駒を移動できない。通常に戻せば再び動かせる。

- 前提：#9・#32・#37・#33（PR #43、`107c0e7`）取り込み済み。仕様の未決なし
- スコープ外：HP 管理・自動の戦闘不能判定、行動順・手番、1マス1体の条件の変更、汎用の状態異常、名前編集・画像アップロード、共有・保存
