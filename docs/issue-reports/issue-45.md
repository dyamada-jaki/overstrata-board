## 2. 目的と範囲

操作に伴う表示の変化で、触っているボタンや駒の画面上の位置がずれる問題を見直す。既知の場面は2つ：開始画面の 0→1 で案内文が消えて「＋」がずれる、未配置の駒を選ぶと移動力の欄が上に出て駒がずれる。駒の設定（移動力・状態切り替え・削除）は、長押し／右クリック／常設の「設定」で開く小さなポップアップへまとめる。

- 前提：#32・#37・#33・#34・#50 は main 取り込み済み（`204e7d1`）。操作要件は 2026-10-31 までに合意済み
- スコープ外：数の直接入力と自動フォーカス（#46）、駒数・番号・移動力の範囲の変更、確定済みの駒の戦闘中の移動力変更、手番管理など
